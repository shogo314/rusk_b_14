# β14の開発記録

β13の完成コミット `be310e0` を引き継いだ `5feb879` から開始した。Rusk 0.0.1 に向けて、配列の走査と具体externの依存関係を整えた。

## 読み取り専用の配列の走査

`readonly Vec<T>` を `for`・`enumerate`・`zip` と、読み取り専用のコールバックを使う `map`・`filter` から扱える。走査位置・添字・先読みの状態を更新する効果と、元の配列やその要素を更新する効果を区別する。`map` が元の要素を返す場合や、`filter` が先読みした値を次の呼び出しで返す場合にも、元の値への読み取り専用の制約を保持する。

`:=` と `copy` の走査状態の規則は従来どおり。構造変更は次の走査時の検査で位置付きエラーとなり、`zip` は片方だけ終わる位置に到達すると長さの不一致を報告する。`noescape` の入力に由来する参照は、イテレータや先読みした値を経由しても呼び出しの外へ返せない。処理系がコールバックの必要な効果を証明できる場合に読み取り専用の走査を認める。[使い方](../library/algorithms.md#readonly-iteration)

### 判定・集計と配列化

読み取り専用の配列や、その配列から作った `map`・`filter` の結果に `all`・`any`・`fold`・`scan`・`to_vec` を適用できるようにした。走査の一時状態やコピーから始める累積値への変更と、入力への変更を区別する。`fold`・`scan` では、ある反復の戻り値が次の反復に持ち越す共有関係を追跡する。空入力や短絡時の戻り値、構造変更の検出、`scan` のスナップショットのコピーは従来の規則を維持する。

`to_vec` の結果は新しい配列だが、元の読み取り専用の要素を共有する場合は読み取り専用の制約を維持する。`noescape` の入力を共有する値を、配列化や累積結果を介して呼び出しの外に返せない。通常・`--no-opt` の両方で、走査の組み合わせ、短絡後の位置、スナップショットの独立性、更新・外部への持ち出しの拒否を検証する。

## 具体externの型付き依存

具体的なextern関数に `template: "true"` を付けると、`code` で `@{call name(Types)->Type}` などの型付き参照を使える。型解決で選んだ関数だけを依存に登録し、トップレベルの実行処理からの依存を推移的にたどる。未使用宣言の型付き参照も検査する。外部シンボルの依存は `depends` に列挙する。従来の生のC++本体は、それまでと同じ依存の扱いを保つ。[記法と制限](extern.md#native-template)

## β13との比較

β13の `be310e0` と、β14の処理系実装 `9026f16` をそれぞれ `cargo build --locked --release` でビルドした。ベンチマーク環境は AMD Ryzen AI 9 HX 370（x86-64）、rustc 1.97.1、GCC 15.2.0。測定は同じ論理CPUに固定した。入力ソースとファイル名をそろえ、各ケースでβ13・β14の実行順をラウンドごとに反転した。最初の1回をウォームアップとし、その後の7回の中央値を記録した。

1. Ruskの `compile 入力.rusk -o 出力.cpp` の経過時間を測る。生成ファイルのサイズはソース記録を含む全体のバイト数。
2. プロジェクト外の同じ一時ディレクトリで、生成ファイルのみを `g++ -std=c++20 -O2 出力.cpp -o 解答` でコンパイルし、その経過時間を測る。
3. 同じ入力で解答を起動し、標準出力の取り込みまでの経過時間を測る。全試行で終了コードと標準出力を検査する。短い解答の実行時間にはプロセスの起動時間も含まれる。

使ったソースと入力は次のとおり。

- A+Bは `examples/aplusb.rusk`。入力は `17 -5`、期待出力は `12`。
- Union-Findは `examples/library_checker/unionfind.test.rusk`。要素40,000個に対し、iが1から19,999までの順に `0 i-1 i` で結合する。iが0から19,999までの順に `1 0 i` を問い合わせ、同じ範囲で `1 i 20000+i` を問い合わせる。この問い合わせの一組を2回繰り返す。期待出力は `1` 20,000行と `0` 20,000行を2回。
- 遅延セグメント木は `examples/beta12/standard_library.rusk` の冒頭から `let uf :=` の直前まで。標準入力は空、期待出力は `40 29 1`。
